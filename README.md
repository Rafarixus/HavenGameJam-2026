# Bounce – Haven Game Jam Vienna 2026
**Bounce** is our submission for the Haven Game Jam in Vienna 2026, developed by a team of three.

## About the Game

Bounce is a puzzle game where your goal is to shoot a ball and manipulate the level so that the ball reaches its target.
The game focuses on aiming, experimenting with different shots, and figuring out how to use the level to guide the ball in the right direction.

## Controls
- F to go to the shooting position
- W, A, S, D, Q, E to go forward, left, backward, right, down or up
- Left mouse click to shoot
- Right mouse click to open or close the build mode
- Left click when in build mode to place
- ESC to get back to the main menu

## Development

Bounce was created during the Haven Game Jam 2026 by a team of three. Due to the limited development time, we had to make some compromises.
The current version still has quite a few bugs, and the gameplay isn't as polished as we originally intended. There are still many things that could be improved, both in terms of mechanics and overall game feel.

## What's Next?

For now, this is what we managed to create during the game jam. Thanks for checking out Bounce!
